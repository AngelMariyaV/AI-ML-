# 🤖 AI & Machine Learning Implementations

Welcome to my repository dedicated to artificial intelligence, machine learning algorithms, and supporting data structure implementations. This project tracks my hands-on journey building core ML concepts from scratch and experimenting with predictive models.

---

## 📂 Repository Contents

### 🧠 Machine Learning & Deep Learning
* **`ann_implementation.py`**: A foundational Artificial Neural Network (ANN) implementation.
* **`backprop_from_scratch.py`**: Custom implementation of the backpropagation algorithm to understand gradient descent and weight updates.
* **`decision_tree.py`**: Supervised learning model using decision trees for classification tasks.
* **`clustering_implementation.py`**: Unsupervised learning algorithms for grouping data points.
* **`next_word_prediction.py`**: A predictive text model designed to forecast subsequent words in a sequence.

### 🖼️ Computer Vision & Generative AI
* **`catdogclassifiernet.py`**: An image classification network built to distinguish between cats and dogs.
* **`genai.py`**: Experiments and scripts focusing on Generative AI capabilities.

### 🎲 Games & Data Structures
* **`dots_and_boxes_game.py`**: An implementation of the classic logic puzzle game "Dots and Boxes".
* **`double_ended_queue_array.py`**: A low-level implementation of a Deque (Double-Ended Queue) using arrays.

---

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Core Focus:** Neural Networks, Supervised/Unsupervised Learning, Algorithm Optimization, Data Structures.
